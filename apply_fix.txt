=== CRITICAL FIX: Prevent Wrong Defenders Being Destroyed ===

THE PROBLEM:
- Array indices (DefIdx) become invalid when defenders die
- Enemy targets Defender #1, but Defender #0 dies first
- Now index #1 points to a DIFFERENT defender
- Wrong defender gets destroyed

THE SOLUTION:
Use the Prop object as identifier instead of array index

=== STEP-BY-STEP CHANGES ===

=== SUMMARY ===

These changes ensure:
✅ Defenders are identified by their Prop object (stable reference)
✅ Array index changes won't affect targeting
✅ Only the correct defender gets destroyed
✅ Animation keys are stable (based on Prop hash, not index)
✅ King animations won't stack

The core principle: Never use array indices as identifiers when the array can change!
